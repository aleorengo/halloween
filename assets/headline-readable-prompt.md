# Readable worn gothic headline

Tool: built-in image generation edit of the existing headline. Final asset: `public/images/headline-worn-gothic-readable.webp`. Native alpha is preserved. The webpage normalizes the lettering to two flat ink colors and adds fine paper-tooth fading through an SVG alpha filter. A 1.5-unit inner erosion softly reduces ink coverage at the edges. There are no large dark stains or metallic edge effects.

## Prompt

Use case: text-localization.
Asset type: transparent raster gothic headline for an elegant Halloween invitation website.
Input image: edit target, existing two-line lettering artwork.
Primary request: fix ONLY the first uppercase letter "A", which currently looks like an N, and make the artwork feel more like flat antique ink printed into rough paper.
Text (verbatim): first line "A wicked"; second line "little night."
The first character MUST be an unmistakable capital A: a single pointed apex at the TOP CENTRE, two diagonal legs spreading out to the bottom left and bottom right, a very clear horizontal crossbar, and a triangular open counter. No tall vertical right stem rising separately, no N-shaped diagonal, no swash that obscures the triangular A silhouette. Keep restrained sharp gothic serifs, but readability takes priority for this one character.
Keep exactly the original wording, two-line composition, spacing, ivory first line, blood-red second line, letter sizes, all other letters and punctuation. Match the original image dimensions and layout.
Materials: flat distressed screenprint / antique ink, fine irregular coverage, minute worn pinholes, slightly absorbed edges, no bevel, no gold rim, no shine, no glow, no embossing or shadow. Remove the shiny edge effect from the lettering. Fine natural aged print wear, not heavy erosion.
Background: actual fully transparent alpha. No solid paper/background, no checkerboard painted into image.
