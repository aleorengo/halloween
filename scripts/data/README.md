# EFF passphrase word list

`eff-large-wordlist.txt` is the unmodified Long Wordlist by the Electronic Frontier Foundation (Joseph Bonneau).

Source: https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt

Usage guidance: https://www.eff.org/dice

Redistributed under Creative Commons Attribution 4.0 International: https://creativecommons.org/licenses/by/4.0/ (EFF copyright policy: https://www.eff.org/copyright).

This public list is used only by the local encryption script. The selected passphrase is never included here or published.
